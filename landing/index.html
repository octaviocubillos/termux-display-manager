Tu Android como estación de trabajo Linux y Servidor Gráfico

Termux Display Manager (TDM) es el motor unificado de entornos de escritorio, servidor de acceso web sin cliente y terminal gráfico multidispositivo para Android y Linux.

Capacidades del Núcleo

Diseñado para Máximo Rendimiento y Simplicidad

Todo lo que necesitas para ejecutar escritorios completos en Android sin root y con cero dependencias externas de Python.

layers

Motor de Pantallas Multi-Backend

Alterna fluidamente entre Termux:X11 (renderizado nativo con aceleración por hardware VirGL), Web HTML5 (noVNC) en cualquier navegador moderno, VNC Móvil y XRDP / Microsoft Remote Desktop.

terminal

Consola Web xterm.js

Accede a un terminal interactivo de Termux con soporte completo de colores ANSI, tmux y redimensionamiento dinámico desde tu navegador.

cleaning_services

Desinstalación Limpia Auditada

Registro SQLite de paquetes en tiempo real. Elimina entornos completos y dependencias huérfanas sin tocar tus archivos personales ni paquetes previos.

monitoring

Telemetría en Tiempo Real

Monitoreo continuo de uso de CPU, temperatura del SoC, consumo de memoria RAM, espacio en disco y latencia RTT vía WebSockets RFC 6455.

install_mobile

PWA & Integración del Sistema

Instalación a nivel de sistema en $PREFIX/opt/termux-display-manager y ejecutable como App PWA en pantalla completa sin barras de navegador.

Instalación en Segundos

Copia y pega este comando en tu consola Termux para desplegar el servidor y gestor TDM.

curl -sSL https://tdm.oton.cl/install | bash

💡 También puedes usar el alias corto: curl -sSL https://tdm.oton.cl/go | bash

Requiere Termux en Android 8.0 o superior. No requiere permisos root.

Comandos de Consola

Lanzador Global tdm

Controla tus pantallas y servicios directamente desde la línea de comandos.

Comando Descripción
tdm start Inicia la pantalla gráfica con el backend y entorno configurado por defecto.
tdm stop Apaga el display y procesos gráficos de forma limpia liberando memoria.
tdm status Muestra el estado en tiempo real, backend activo y URLs de acceso local y LAN.
tdm service restart Reinicia el demonio HTTP/WebSocket en segundo plano bajo termux-services.
tdm install <entorno> Descarga y configura un entorno (xfce4, lxqt, openbox, etc.).
tdm uninstall Desinstalación selectiva auditada que limpia solo paquetes registrados por TDM.
