v0.0.55 Última Versión Septiembre 2026
commit 1636d89
build_circle Correcciones Críticas y Estabilidad
  • • Arranque y Configuración de i3 WM: Generación automática de ~/.config/i3/config y autoinicio de terminal interactivo para evitar que i3 se congele o aborte por falta de teclado físico en Termux:X11 o NoVNC.
  • • Purga y Detección de Desinstalación: display_manager.get_installed_desktop() ahora devuelve installed: False cuando no hay entornos instalados, eliminando estados fantasma al recargar la página.
  • • Limpieza Total de Binarios y Dpkg: En uninstall_desktop.sh se implementó purga forzada dpkg -P --force-all y eliminación exhaustiva de ejecutables residuales en $PREFIX/bin/.
  • • Sincronización Visual en Instalación: Se oculta el banner del escritorio anterior durante la instalación para evitar contradicciones visuales (ej. mostrar XFCE arriba mientras abajo se instala i3).
verified_user Permisos y Apertura Automática de X11
  • • Solicitud Automática en Instalación: El instalador curl -sSL https://tdm.oton.cl/install | bash dispara el intent de Android para abrir directamente la pantalla de permisos "Mostrar sobre otras aplicaciones" para Termux y Termux:X11.
  • • Comando CLI tdm permissions: Comando interactivo para reabrir y comprobar la pantalla de configuración de permisos en cualquier momento.
  • • Timeout WebSocket Ampliado (10 min): Temporizador de peticiones RPC ampliado a 600 segundos para operaciones pesadas de paquetes con latido activo (heartbeat ping) cada 5 segundos.
palette Interfaz Web y PWA
  • • Consola Silenciosa por Defecto: El cajón de logs ya no se abre automáticamente al instalar, desinstalar o actualizar. Solo se abre bajo demanda al pulsar el botón Ver Log.
  • • Selector de Entornos Dinámico: Tarjetas con atributos data-de-id que sincronizan el foco y la selección en tiempo real.
v0.0.54 Septiembre 2026
commit 6c07f1c
add_circle Nuevas Funcionalidades
  • • Barra de Progreso Real Cuantitativa (0% al 100%): Telemetría paso a paso estructurada con marcadores [TDM_PROGRESS:XX:Paso] en scripts y cálculo dinámico en tiempo real vía WebSockets y REST.
  • • Desinstalador CLI de Entornos: Soporte de desinstalación de escritorios directamente desde la terminal con tdm uninstall --desktop <nombre|all>.
  • • Auto-Optimización de Almacenamiento: Invocación automática de autoremove --purge y autoclean tras cualquier instalación o desinstalación.
cached PWA y Políticas de Caché
  • • Estrategia Network-First en Service Worker: Garantiza que la PWA siempre descargue la última versión de la aplicación desde Termux sin quedarse atrapada en versiones viejas.
  • • Cabeceras HTTP Estrictas: Directivas Cache-Control: no-cache, no-store, must-revalidate en el servidor HTTP Python nativo para respuestas JSON y archivos HTML/JS.
v0.0.53 Agosto 2026
autorenew Actualizador Inteligente
  • • Botón de Actualización Condicional: Botón en la barra superior del panel web que solo aparece cuando se detecta una nueva versión en el servidor o repositorio.
  • • Directorio de Trabajo Robusto: Corrección de fallos en ejecución de scripts cuando el directorio padre se elimina o se altera durante el empaquetado.
v0.0.50 Agosto 2026
rocket_launch Lanzamiento de Arquitectura Unificada
  • • Servidor Asíncrono Zero-Dependency: Servidor HTTP y WebSocket puro en Python basado en asyncio sin frameworks externos.
  • • Integración NoVNC & WebSockets RFC 6455: Puente directo para acceder al escritorio desde cualquier navegador web sin instalar clientes.
  • • Catálogo Maestro de Escritorios: Soporte inicial para XFCE4, KDE Plasma, MATE, LXQt, Openbox e i3 Window Manager.
